# 🍲 Sabor de Minas: cardápio online

Cardápio digital de um restaurante fictício de **comida mineira**, feito com HTML e CSS.

> *O melhor da roça, no seu prato.*

![Logo Sabor de Minas](assets/img/Logo%20Minas.png)

## Seções do cardápio

- **Entradinhas**: torresmo, linguiça artesanal, mandioca frita, pão de queijo...
- **Pratos principais**: feijoada, frango com quiabo, costelinha de porco, vaca atolada, angu, pernil assado
- **Sobremesas**: doce de leite, romeu e julieta, ambrosia, pudim, quitandas
- **Bebidas**: caipirinha, clericot, cerveja long neck e refrigerante

Cada item aparece em um card com foto, nome e preço, e o menu no topo leva direto para cada seção.

## Tecnologias

- HTML5
- CSS3 com **layout responsivo** (media query para celular)
- Google Fonts (Cal Sans e Kalam)
- [Font Awesome](https://fontawesome.com/) (ícones)

## Estrutura

```
├── index.html     # cardápio
├── style.css      # estilos
└── assets/img/    # logo e fotos dos pratos
```

## Como rodar

Não precisa instalar nada:

1. Clone o repositório
   ```bash
   git clone https://github.com/julio-aurelio/projeto-cardapio.git
   ```
2. Abra o `index.html` no navegador.
